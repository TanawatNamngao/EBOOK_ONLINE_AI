### รายวิชาระบบฐานข้อมูล [31-407-102-301] ประจำปีการศึกษา 2569

## 1. ภาพรวมของระบบ (System Overview)
ระบบ **EBOOK_ONLINE** เป็นเว็บแอปพลิเคชันสำหรับจำหน่ายหนังสือดิจิทัล (E-Book) พัฒนาขึ้นโดยยึดหลักการออกแบบฐานข้อมูลเชิงสัมพันธ์ระดับ 3NF (Third Normal Form) ควบคู่กับสถาปัตยกรรมการจัดเก็บข้อมูลแบบคู่ขนาน (Hybrid Dual-Database Engine):
- **Local Embedded Cache (SQLite):** มอบความเร็วในการตอบสนองคำสั่งซื้อแบบ Low Latency บนเครื่องโฮสต์
- **Cloud Database (Supabase PostgreSQL):** รองรับการสำรองและเข้าถึงข้อมูลระดับองค์กรบนคลาวด์ พร้อมระบบ Realtime Sync

ระบบมุ่งเน้นความปลอดภัยขั้นสูงสุดในการส่งมอบทรัพย์สินดิจิทัล โดยมีกลไกสกัดกั้นการเข้าถึงไฟล์ (Security Download Gate HTTP 403) จนกว่าผู้ดูแลระบบจะตรวจสอบสลิปและกดยืนยันคำสั่งซื้อ

| :--- | :--- | :--- |

## 3. ข้อกำหนดเชิงฟังก์ชัน (Functional Requirements: FR)

### FR-01: การลงทะเบียนและการเข้าสู่ระบบ (Authentication & Registration)
- ระบบต้องรองรับการสมัครสมาชิกใหม่โดยกำหนด Username และ Email ที่ไม่ซ้ำกันในระบบ (`UNIQUE constraint`)
- รหัสผ่านต้องได้รับการแฮชและตรวจสอบความปลอดภัยก่อนบันทึก
- เมื่อสมัครสมาชิกสำเร็จ ระบบต้องสร้างตะกร้าสินค้า (`cart`) ประจำตัวผู้ใช้คนนั้นโดยอัตโนมัติ

### FR-02: การสืบค้นและคัดกรองหนังสือ (Catalog Browsing & Search)
- ผู้ใช้สามารถค้นหา E-Book ตามชื่อเรื่อง (`title`), คำอธิบาย (`description`), ชื่อผู้แต่ง (`authors.name`)
- รองรับการกรองตามหมวดหมู่ (`category_id`) และเรียงลำดับราคา (น้อยไปมาก / มากไปน้อย)
- ซ่อนหนังสือที่ปิดการขาย (`is_published = 0`) ไม่ให้ปรากฏในหน้าหลักของลูกค้า

### FR-03: การจัดการตะกร้าสินค้า (Cart Management)
- สมาชิกสามารถเพิ่มหนังสือลงในตะกร้า ลบสินค้าออก และดูยอดรวมราคาทั้งหมดได้
- ระบบต้องป้องกันการเพิ่มสินค้าที่ปิดการขายเข้าสู่ตะกร้า (HTTP 400 Bad Request)
- ป้องกันการเพิ่มสินค้าซ้ำซ้อนในตะกร้าเดียวกัน

### FR-04: การสั่งซื้อและสร้างคำสั่งซื้อ (Checkout & Order Creation)
- เมื่อกดยืนยันการสั่งซื้อ ระบบต้องคัดลอกรายการจาก `cart_items` ไปยัง `orders` และ `order_items`
- บันทึกสถานะเริ่มต้นของคำสั่งซื้อเป็น `pending` (รอดำเนินการ)
- ระบบต้องล้างรายการในตะกร้าสินค้าทันทีหลังจากสร้างคำสั่งซื้อสำเร็จ

### FR-05: การชำระเงินจำลองและการส่งสลิป (Payment & Slip Upload)
- จำลองการชำระเงินผ่านระบบ PromptPay QR Code หรือโอนเงินผ่านบัญชีธนาคาร
- ผู้ใช้สามารถอัปโหลดไฟล์ภาพสลิปจำลอง (รองรับ SVG, PNG, JPG)
- ข้อมูลการชำระเงินจะถูกบันทึกลงในตาราง `payments` โดยมีสถานะ `submitted`

### FR-06: การตรวจสอบและอนุมัติคำสั่งซื้อ (Admin Order Verification)
- แอดมินสามารถเปิดดูรายการคำสั่งซื้อสถานะ `pending` พร้อมแสดงภาพสลิปที่แนบมาแบบ Side-by-side
- แอดมินสามารถกดปุ่ม "อนุมัติคำสั่งซื้อ (Confirm)" หรือ "ปฏิเสธ/ยกเลิก (Cancel)"
- เมื่ออนุมัติ สถานะของออเดอร์จะเปลี่ยนเป็น `confirmed` และระบบจะสร้างสิทธิ์ดาวน์โหลดในตาราง `download_links` พร้อมอายุการใช้งานและจำนวนครั้งสูงสุด (`max_downloads = 5`)

### FR-07: การควบคุมสิทธิ์การดาวน์โหลดไฟล์ (Secure Download Access Gate)
- การเข้าถึงไฟล์ E-Book ต้องกระทำผ่าน Token ที่ปลอดภัย (`/api/download/:token`)
- หากคำสั่งซื้อยังอยู่ในสถานะ `pending` หรือ `cancelled` ระบบต้องส่งคืนรหัส HTTP 403 Forbidden
- หาก Token ถูกต้องและออเดอร์อนุมัติแล้ว ระบบจะส่งมอบไฟล์ PDF หรือตัวอย่าง E-Book และเพิ่มค่า `download_count` ขึ้น 1 ครั้ง

### FR-08: รายงานวิเคราะห์ธุรกิจเชิงลึก 4 ด้าน (Business Analytics Reports)
- **รายงานที่ 1 (Sales Over Time):** ยอดขายและจำนวนคำสั่งซื้อจำแนกตามช่วงเวลา (รายเดือน/รายวัน)
- **รายงานที่ 2 (Bestselling Books):** อันดับหนังสือขายดีที่สุด เรียงตามยอดจำหน่ายและจำนวนเล่มที่ขายได้
- **รายงานที่ 3 (Sales by Category):** ส่วนแบ่งยอดขายจำแนกตามหมวดหมู่ พร้อมสัดส่วนเปอร์เซ็นต์ (% Market Share)
- **รายงานที่ 4 (Customer Spending & Frequency):** พฤติกรรมการซื้อ มูลค่าการซื้อสะสม และความถี่ของลูกค้าแต่ละราย
- ระบบต้องรองรับการดาวน์โหลดรายงานทุกฉบับออกมาเป็นไฟล์ CSV มาตรฐาน UTF-8 BOM

### FR-09: การจัดการคลังหนังสือและหมวดหมู่ (Book Inventory Management)
- แอดมินสามารถเพิ่มหนังสือใหม่, แก้ไขข้อมูลราคา, ผู้แต่ง, หมวดหมู่ และสถานะเปิด/ปิดการขายได้
- ป้องกันการตั้งราคาติดลบด้วย CHECK Constraint (`price >= 0`) ในระดับฐานข้อมูล

### FR-10: การซิงโครไนซ์ข้อมูลบนคลาวด์ (Cloud Real-Time Sync)
- เมื่อมีคำสั่งซื้อหรือการอัปเดตสลิปในฐานข้อมูลท้องถิ่น ระบบจะส่งข้อมูลไปอัปเดตบน Supabase PostgreSQL อัตโนมัติ
- แอดมินสามารถกดปุ่ม Sync บน Admin Portal เพื่อดึงข้อมูลอัปเดตระหว่าง SQLite และ Supabase ได้ตลอดเวลา

## 4. ข้อกำหนดเชิงคุณภาพ / ไม่ใช่ฟังก์ชัน (Non-Functional Requirements: NFR)

1. **ความปลอดภัยของข้อมูล (Security):**
   - มีการแยกสิทธิ์ระหว่าง Customer และ Admin อย่างเด็ดขาด (Role-Based Access Control)
   - ป้องกันการเข้าถึงไฟล์โดยตรง (Direct File Traversal Protection)
   - ปกป้อง Endpoint หลังบ้านจากการเรียกใช้โดยไม่ได้รับอนุญาต
2. **บูรณภาพของข้อมูล (Data Integrity):**
   - โครงสร้างฐานข้อมูลสอดคล้องกับมาตรฐาน 3NF (ไม่มี Partial หรือ Transitive Dependency)
   - บังคับใช้ Foreign Keys, NOT NULL, UNIQUE, CHECK ในระดับสคีมาฐานข้อมูล
3. **ประสิทธิภาพและความเร็ว (Performance):**
   - เวลาในการตอบสนอง (Response Time) ของ API ไม่เกิน 150ms สำหรับการค้นหาและดึงแค็ตตาล็อก
   - มีการสร้าง Index บนคอลัมน์ที่มีการสืบค้นบ่อย เช่น `user_id`, `status`, `category_id`, `token`
4. **ความพร้อมใช้งาน (Availability):**
   - แอปพลิเคชันถูกเผยแพร่บน Cloud Platform (Render) ใช้งานได้ตลอด 24 ชั่วโมง
5. **การเข้าถึงสำหรับทุกคน (Accessibility: a11y):**
   - รองรับมาตรฐาน WCAG 2.1 Level AA (Contrast Ratio >= 4.5:1, Keyboard Focus, ARIA Tags)

## 6. สรุปรายการ RESTful API Endpoints

| Method | Endpoint | สิทธิ์การเข้าถึง | หน้าที่การทำงาน |
| :--- | :--- | :---: | :--- |
| `POST` | `/api/auth/register` | สาธารณะ | สมัครสมาชิกใหม่ พร้อมสร้างตะกร้าสินค้าอัตโนมัติ |
| `POST` | `/api/auth/login` | สาธารณะ | ตรวจสอบตัวตนผู้ใช้ และส่งคืนข้อมูลบทบาท (Role) |
| `GET` | `/api/ebooks` | สาธารณะ | ดึงรายการหนังสือ E-Book ทั้งหมด (รองรับ `search` & `category`) |
| `GET` | `/api/ebooks/:id` | สาธารณะ | ดึงรายละเอียดหนังสือรายเล่ม |
| `GET` | `/api/categories` | สาธารณะ | ดึงรายชื่อหมวดหมู่หนังสือทั้งหมด |
| `GET` | `/api/cart` | ผู้ใช้ล็อกอิน | ดึงรายการหนังสือในตะกร้าของผู้ใช้ (`x-user-id`) |
| `POST` | `/api/cart/items` | ผู้ใช้ล็อกอิน | เพิ่มหนังสือลงในตะกร้า |
| `DELETE`| `/api/cart/items/:id` | ผู้ใช้ล็อกอิน | ลบหนังสือออกจากตะกร้า |
| `POST` | `/api/orders/checkout` | ผู้ใช้ล็อกอิน | สั่งซื้อสินค้าในตะกร้า และสร้างคำสั่งซื้อสถานะ `pending` |
| `GET` | `/api/orders/my-orders` | ผู้ใช้ล็อกอิน | ดึงประวัติคำสั่งซื้อและลิงก์ดาวน์โหลดของตนเอง |
| `POST` | `/api/orders/:id/payment` | ผู้ใช้ล็อกอิน | แจ้งชำระเงินและอัปโหลดไฟล์สลิปจำลอง |
| `GET` | `/api/download/:token` | ผู้มีสิทธิ์ | ดาวน์โหลดไฟล์ E-Book (บล็อก 403 หากออเดอร์ยังไม่ยืนยัน) |
| `GET` | `/api/admin/orders` | แอดมิน | ดูรายการคำสั่งซื้อทั้งหมด พร้อมตัวกรองสถานะ |
| `PUT` | `/api/admin/orders/:id/confirm` | แอดมิน | ยืนยันคำสั่งซื้อ และเปิดสิทธิ์ดาวน์โหลดหนังสือ |
| `PUT` | `/api/admin/orders/:id/cancel` | แอดมิน | ยกเลิกคำสั่งซื้อ |
| `GET` | `/api/admin/reports/:reportId` | แอดมิน | คำนวณรายงานวิเคราะห์ 4 ด้านด้วย SQL ขั้นสูง |
| `GET` | `/api/admin/reports/:reportId/export-csv` | แอดมิน | ส่งออกรายงานเป็นไฟล์ CSV (UTF-8 BOM) |
| `POST` | `/api/admin/sync-supabase` | แอดมิน | ทริกเกอร์การซิงค์ข้อมูลกับฐานข้อมูล Supabase Cloud |
