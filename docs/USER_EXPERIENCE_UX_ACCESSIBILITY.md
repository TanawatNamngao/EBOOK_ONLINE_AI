### 3.3 รายละเอียดการประเมินตามหลักการ 4 ประการของ WCAG 2.1

#### 1. รับรู้ได้ (Perceivable)
* **อัตราส่วนความเปรียบต่างของสี (Color Contrast Ratio):**
  - ข้อความหลักบนพื้นหลังมี Contrast Ratio สูงกว่า `7.5:1` (เกณฑ์ขั้นต่ำ WCAG AA คือ `4.5:1` และ AAA คือ `7.0:1`)
  - ข้อความหัวเรื่องและปุ่มสำคัญใช้ชุดสี `#1e293b` บนพื้นหลัง `#ffffff` และ `#ffffff` บนพื้นหลัง `#2563eb` ซึ่งผ่านเกณฑ์ระดับสูงสุด
* **คำอธิบายภาพสำหรับเนื้อหาที่ไม่ใช่ข้อความ (Alt Text):**
  - ภาพหน้าปกหนังสือ E-Book ทุกเล่มมีแอตทริบิวต์ `alt="ภาพปกหนังสือ [ชื่อเรื่อง] โดย [ชื่อผู้แต่ง]"` ครบถ้วน 100%
  - ภาพสลิปชำระเงินจำลองมี `alt="หลักฐานสลิปการชำระเงินสำหรับคำสั่งซื้อ [รหัส]"`
* **โครงสร้างหัวเรื่องเชิงความหมาย (Semantic Headings):**
  - มีการจัดลำดับหัวเรื่องอย่างถูกต้อง `h1` ➔ `h2` ➔ `h3` ไม่มีข้ามระดับ ช่วยให้โปรแกรมอ่านหน้าจอ (Screen Reader) นำทางได้อย่างถูกต้อง

#### 2. ใช้งานได้ (Operable)
* **การนำทางด้วยแป้นพิมพ์อย่างสมบูรณ์ (Full Keyboard Navigation):**
  - ผู้ใช้สามารถกดปุ่ม `Tab` และ `Shift + Tab` เพื่อเลื่อนโฟกัสไปยังปุ่ม ลิงก์ และฟอร์มกรอกข้อมูลได้ครบทุกจุด
  - รองรับการกด `Enter` หรือ `Space` เพื่อเปิดโมดอลหรือยืนยันคำสั่งซื้อ
  - สามารถกดปุ่ม `Escape (Esc)` เพื่อปิดหน้าต่างโมดอลตะกร้าหรือสลิปได้อย่างรวดเร็ว
* **การแสดงผลจุดโฟกัสที่ชัดเจน (Visible Focus Indicators):**
  - ปรับแต่งเส้นขอบโฟกัส `:focus-visible` เป็นวงแหวนสีฟ้าเด่นชัด (`outline: 3px solid #3b82f6; outline-offset: 2px`) ป้องกันการหลงตำแหน่ง
* **ขนาดพื้นที่สัมผัสที่เหมาะสม (Touch Target Size):**
  - ปุ่มกดทุกปุ่มมีขนาดไม่ต่ำกว่า `44 x 44 พิกเซล` ตามเกณฑ์ Mobile Friendly ทำให้กดง่ายบนสมาร์ตโฟนและแท็บเล็ต

#### 3. เข้าใจได้ (Understandable)
* **การระบุภาษาและข้อความที่สื่อความหมาย (Language & Clarity):**
  - หน้าเว็บกำหนดแท็ก `<html lang="th">` พร้อมแสดงข้อความสองภาษา (ไทย/อังกฤษ) อย่างชัดเจน
  - ข้อผิดพลาดในการกรอกฟอร์มแสดงข้อความอธิบายที่เข้าใจง่าย (เช่น *"กรุณาระบุ Username อย่างน้อย 3 ตัวอักษร"* หรือ *"ราคาสินค้าต้องไม่ติดลบ"*)
* **การแสดงสถานะด้วยสัญลักษณ์ร่วมกับสี (Non-Color Dependent Status):**
  - ป้ายสถานะของคำสั่งซื้อไม่ได้พึ่งพาเฉพาะสี แต่มีข้อความและไอคอนกำกับอย่างชัดเจนเสมอ:
    - 🟡 รอตรวจสอบ (`pending`)
    - 🟢 ได้รับการอนุมัติแล้ว (`confirmed`)
    - 🔴 ยกเลิกแล้ว (`cancelled`)
  - ช่วยให้ผู้ใช้ที่มีภาวะตาบอดสี (Color Vision Deficiency) สามารถเข้าใจสถานะได้อย่างแม่นยำ

#### 4. แข็งแกร่งเชิงเทคนิค (Robust)
* **การใช้แท็กเชิงความหมายตามมาตรฐาน HTML5 (Semantic HTML5):**
  - ใช้ `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>` แทนการใช้แท็ก `<div>` เปล่า
* **การกำหนดบทบาทและแอตทริบิวต์ ARIA (Accessible Rich Internet Applications):**
  - โมดอลมีแอตทริบิวต์ `role="dialog"`, `aria-modal="true"`, และ `aria-labelledby`
  - ปุ่มเปิด/ปิดมี `aria-expanded` เพื่อแจ้งสถานะแก่ Screen Reader
  - จุดแจ้งเตือนมี `role="status"` หรือ `aria-live="polite"`
