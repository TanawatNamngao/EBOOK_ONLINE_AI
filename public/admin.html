รายงานที่ 1: สรุปยอดขายและจำนวนเล่มที่ขายได้ของหนังสือแต่ละเล่ม

คำถามที่ตอบ: ดูว่าหนังสือแต่ละเล่มขายได้กี่เล่ม และได้เงินรวมเท่าไหร่?

👤 ผู้รับผิดชอบอธิบาย: นายธนวัฒน์ นามเหง้า (67332110293-4)
ลำดับ ชื่อเรื่อง E-Book จำนวนเล่มที่ขายได้ ยอดขายรวม (บาท)
🔍 ดูคำสั่ง SQL สำหรับรายงานนี้ (JOIN, GROUP BY, COUNT, SUM, ORDER BY) 
SELECT 
    ebooks.title,
    COUNT(order_items.order_item_id) AS total_sold,
    SUM(order_items.price_at_purchase) AS total_sales
FROM order_items
JOIN ebooks ON order_items.ebook_id = ebooks.ebook_id
GROUP BY ebooks.title
ORDER BY total_sales DESC;

รายงานที่ 2: จัดอันดับ E-Book ขายดีที่สุด 3 อันดับแรก (Top 3 Bestsellers)

คำถามที่ตอบ: หาหนังสือ 3 อันดับแรกที่มียอดสั่งซื้อสูงสุดไปจัดโปรโมชันหน้าร้าน?

👤 ผู้รับผิดชอบอธิบาย: นายธนวัฒน์ นามเหง้า (67332110293-4)
อันดับ ชื่อเรื่อง E-Book จำนวนเล่มที่ขายได้
🔍 ดูคำสั่ง SQL สำหรับรายงานนี้ (JOIN, GROUP BY, COUNT, ORDER BY, LIMIT) 
SELECT 
    ebooks.title,
    COUNT(order_items.order_item_id) AS total_sold
FROM order_items
JOIN ebooks ON order_items.ebook_id = ebooks.ebook_id
GROUP BY ebooks.title
ORDER BY total_sold DESC
LIMIT 3;

รายงานที่ 3: สรุปประสิทธิภาพช่องทางชำระเงินและยอดเฉลี่ยต่อบิล

คำถามที่ตอบ: ดูว่าลูกค้าชอบจ่ายเงินทางไหนมากที่สุด และเฉลี่ยบิลละกี่บาท?

👤 ผู้รับผิดชอบอธิบาย: นายภานุวัฒน์ แสงเครือ (67332110248-5)
ช่องทางการชำระเงิน จำนวนคำสั่งซื้อ ยอดขายรวม (บาท) ยอดเฉลี่ยต่อออเดอร์ (บาท)
🔍 ดูคำสั่ง SQL สำหรับรายงานนี้ (JOIN, GROUP BY, COUNT, SUM, AVG, ROUND, ORDER BY) 
SELECT 
    payments.payment_method,
    COUNT(orders.order_id) AS total_orders,
    SUM(orders.total_amount) AS total_sales,
    ROUND(AVG(orders.total_amount), 2) AS avg_sales
FROM orders
JOIN payments ON orders.order_id = payments.order_id
WHERE orders.status = 'confirmed'
GROUP BY payments.payment_method
ORDER BY total_sales DESC;

รายงานที่ 4: ค้นหาลูกค้าประจำที่ซื้อตั้งแต่ 2 ครั้งขึ้นไป (Customer Insights)

คำถามที่ตอบ: หาฐานลูกค้าที่กลับมาซื้อซ้ำตั้งแต่ 2 ครั้งขึ้นไปเพื่อมอบสิทธิพิเศษ Loyalty Reward?

👤 ผู้รับผิดชอบอธิบาย: นายภานุวัฒน์ แสงเครือ (67332110248-5)
ลำดับ ชื่อ-นามสกุลลูกค้า จำนวนครั้งที่สั่งซื้อ ยอดเงินซื้อสะสมรวม (บาท)
🔍 ดูคำสั่ง SQL สำหรับรายงานนี้ (JOIN, GROUP BY, HAVING, COUNT, SUM, ORDER BY) 
SELECT 
    users.full_name,
    COUNT(orders.order_id) AS total_orders,
    SUM(orders.total_amount) AS total_spent
FROM users
JOIN orders ON users.user_id = orders.user_id
WHERE orders.status = 'confirmed'
GROUP BY users.full_name
HAVING COUNT(orders.order_id) >= 2
ORDER BY total_spent DESC;
